# AI Decor setup

The frontend is a plain HTML/CSS/JavaScript site. The `backend` folder is a small
Express server because API keys must stay on the server and never go into
browser JavaScript.

## 1. Install Node.js

Install the current Node.js LTS from https://nodejs.org/ and check:

```powershell
node --version
npm --version
```

## 2. Get a free Cloudflare key

Room images are generated by Cloudflare Workers AI
(`@cf/black-forest-labs/flux-2-klein-9b`) with a free allowance of
10,000 neurons per day.

1. Create a free account at https://dash.cloudflare.com/sign-up
2. Copy the **Account ID** from the dashboard.
3. Create an API token using the Workers AI template with
   `Workers AI - Read` and `Workers AI - Edit`.
4. Copy `backend/.env.example` to `backend/.env` and fill in:

```text
IMAGE_PROVIDER=cloudflare
CF_ACCOUNT_ID=your-account-id
CF_API_TOKEN=your-token
PORT=5000
```

Never put these values in frontend files or commit `.env`. The backend
`.gitignore` already excludes `.env` and `node_modules`.

## Free limit

A room plus up to three catalog references uses roughly 1,500 to 2,000 neurons,
so the free allowance normally supports about five generations per day. The
allowance resets daily.

## Optional: Gemini instead

Gemini image generation is paid-only. If billing is enabled in Google AI
Studio, set:

```text
IMAGE_PROVIDER=gemini
GEMINI_API_KEY=your-gemini-key
PORT=5000
```

## 3. Start the backend

```powershell
cd backend
npm install
npm start
```

Check it:

```powershell
Invoke-WebRequest http://localhost:5000/api/health
```

## 4. Start the frontend

Open the project root in VS Code and use Live Server on:

`http://localhost:3002/frontend/pages/user/home/index.html`

Choose a room image, select one or more products, choose a style, and click
**Generate my room**.

## How it works

- The browser sends the room photo and catalog references as multipart data.
- Cloudflare input images are resized to at most 512 by 512 pixels.
- The room output keeps the room photo's aspect ratio, up to 1024 pixels.
- At most three catalog references are sent after the room photo.
- Every selected product is named in the prompt, even when no reference image
  is available.
- Generated output is best effort and may not copy a catalog product exactly.

## Troubleshooting

- **CF_ACCOUNT_ID or CF_API_TOKEN missing:** fill in `backend/.env`, stop the
  backend, and restart `npm start`.
- **Cloudflare rejected the credentials:** verify the Account ID and that the
  token has Workers AI Read and Edit permissions.
- **Daily free image limit reached:** wait until the daily reset or use a paid
  Cloudflare plan.
- **Cloudflare timeout:** retry with fewer selected reference products.
- **CORS error:** use Live Server on port 3002.
- **Image rejected:** use JPG, JPEG, PNG or WEBP under 10 MB.
- **Gemini `limit: 0`:** enable Gemini billing or remain on Cloudflare.
